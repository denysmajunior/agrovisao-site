# AgroVisão — Consultoria Agrícola

Site institucional estático da AgroVisão (HTML, CSS e JavaScript puros, sem dependências).

## Páginas
- `index.html` — Home
- `sobre.html`, `servicos.html`, `projetos.html`, `galeria.html`, `vendas.html`, `contato.html`
- `projeto-*.html` — uma página para cada um dos 18 projetos

## Estrutura
- `assets/css/style.css` — estilos (cores no bloco `:root`)
- `assets/js/main.js` — menu, formulário/WhatsApp, filtros, animações e contadores
- `assets/img/` — imagens otimizadas em WebP

## Publicação
Basta enviar a pasta para qualquer hospedagem estática (GitHub Pages, Vercel, Netlify, Hostinger, cPanel).
